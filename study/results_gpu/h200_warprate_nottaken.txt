## Reading (cycles at 1.98 GHz; executed SASS per outer iteration in brackets)

1. "Never-taken branch every N" as written in PTX does NOT give a not-taken branch in SASS. ptxas moves the
   out-of-line target block inline and inverts the predicate: `@!P1 BRA skip; BSSY; <loop>; BSYNC; skip:`. The
   branch is then taken every time, and nt1/nt2/nt4/nt16 compile to the same code as the always-taken forward
   variants ft1/ft4/ft16 (predicate inverted only). Their times are identical: these rows measure a TAKEN forward
   branch.
   | variant | cyc/iter | executed SASS | cyc/instr | cyc per branch over base |
   |---|---|---|---|---|
   | base, no branch | 144.0 | 128 ALU + 3 loop = 131 | 1.10 | - |
   | taken fwd every 1 (ft1 = "nt1") | 1597.0 | 128 + 128 BRA + 3 = 259 | 6.17 | (1597-144)/128 = 11.4 |
   | every 2 ("nt2") | 920.0 | 128 + 64 + 3 = 195 | 4.72 | 12.1 |
   | every 4 (ft4 = "nt4") | 511.0 | 128 + 32 + 3 = 163 | 3.13 | 11.5 |
   | every 16 (ft16 = "nt16") | 275.0 | 128 + 8 + 3 = 139 | 1.98 | 16.4 |
   (the taken branch skips its BSSY/BSYNC, so only the BRA executes; consistent with the earlier
   br_every1/4/16 = 11.2 cycles per branch / 3.88 / 2.13 cycles per instruction)

2. A real not-taken branch: loops with a run-time trip count T (lt4: 4 ALU per inner iteration, lt16: 16 ALU).
   Each inner iteration = N ALU + UIADD3 (uniform counter) + ISETP + BRA backward. The back-edge is taken T-1
   times and NOT taken once per entry; entry adds one UMOV. Per group:
   | kernel | T=1 | T=2 | T=4 | T=8 | slope (cycles per taken iteration) | T=1 minus slope (= not-taken minus taken, + UMOV) |
   |---|---|---|---|---|---|---|
   | lt4 (32 groups/iter) | 30.8 | 60.3 | 119.3 | 237.3 | 29.5 (exactly linear) | 1.3 |
   | lt16 (8 groups/iter) | 39.4 | 72.4 | 138.4 | 270.4 | 33.0 (exactly linear) | 6.4 |
   - A not-taken back-edge iteration costs the same as a taken one within 1-6 cycles. There is no large
     not-taken discount and no taken penalty beyond it.
   - These loops are latency-bound, not issue-bound. 12 more ALU ops per iteration (lt4 -> lt16) add only
     3.5 cycles: about 26-29 cycles per iteration are the counter -> ISETP -> BRA dependence plus branch
     resolution. That is not a pure per-branch issue cost.

3. History dependence (kernel pat): every 4 ALU ops a Galois-LFSR step (4 SASS: LOP3 with predicate out, SHF,
   IMAD.MOV, LOP3) sets P from the low bit, then `@!P BRA skip` over an inlined block (BSSY, VIADD, ISETP,
   @P BRA [not taken], BSYNC). Same code for every pattern; the pattern only changes the data:
   | pattern | cyc/iter (32 branches) | per branch vs pat_nobr (462-463) |
   |---|---|---|
   | P never true -> BRA taken every time (block skipped) | 857.0 | 12.3 |
   | P always true -> BRA not taken, block runs | 1896.0 | 44.8 (includes the block: 2 ALU + a second not-taken BRA + BSSY/BSYNC) |
   | alternate | 1369.0 | mean of the two = 1376.5 (-0.5%) |
   | LFSR pseudo-random (~50%) | 1373.2 | -0.3% from the mean |
   - The cost is a linear mix of the two outcomes; alternating and random sequences cost the same.
     **No sign of a branch predictor or of any history effect.**
   - pat_nobr = the same LFSR work with P consumed by SELP+IADD instead of a branch: 462-463 for all patterns.

Not done: a not-taken forward branch with an empty fall-through (ptxas always inverts or if-converts it);
backward-taken in isolation beyond the loop form above.
